# タスク002 実装第1弾 報告

完了日: 2026-11-01  
対象: 月進行・HUD・成長・収入・設定土台  
公開先: https://oosawak.github.io/sengoku-life-sim/

## 実装内容

1. **月進行エンジン:** 年月を状態として持ち、経過時間を蓄積して月を進める方式にした。停止と×1/×5/×10/×20を実装し、年月・同月内のID順でイベントを処理する。月のない既存イベントは1月扱いを維持。選択中は時間を止める。
2. **誕生月:** 政宗9月、成実12月を指定資料に基づいて設定。月が不確かな頼澄6月・義光1月・兼続4月は「割当て（試作値）」と明記。誕生月に年齢を更新し、短い誕生日ログを出す。人物ファイルの生没年・出来事・宿願本文は変えていない。
3. **常時表示:** 生涯画面に5能力の棒と数値、評判、所持金、健康状態語、年月・年齢・身分段階を追加。能力・金銭・健康の変化は符号付きの短い表示とログに出す。選択前には既存 effect の見込みも項目別に表示する。画面文言は「日々の心がけ」とし、既存の紙色・朱色の配色を維持して参考画面の黒・金の意匠は使っていない。
4. **成長:** 武芸稽古・学問・政務・人付き合い・家の仕事・休養を選べる。能力は0.12/月（当初0.05案を70年計測で調整）、80以上で半分、95以上で1/4。所持金不足時は訓練を休み、記録する。50〜64歳は武芸の伸びの半分、65歳以降は全量を知略へ配分。誕生日ごとに50歳から武勇を年0.5、65歳から年1.0下げ、下げた分を知略へ移す。能力上限で移しきれない分は失われる。
5. **収入とお金:** 通貨は貫、所持金は0.1貫単位。開始金は国衆4／家老級8／大名級20貫。年収は家中の者2／侍大将6／城主・重臣18／家中筆頭36／大名60貫。人物の初期 rank に応じた段階で開始し、月初に年収を12分割支給する。端数は繰り越し、12か月で年収と一致する。役職段階が変われば年収を切り替えられる構造だが、昇進自体は第2弾。
6. **健康:** 内部値0〜100、開始100。HUDは健やか／不調／重篤の状態語で示し、第1弾では休養による月+1回復だけを実装。病気・怪我・死亡判定や寿命延長は未実装で、従来の史実没年＋既存の寿命 effect を維持。
7. **頻度設定:** GAME_CONFIG に少ない／ふつう／多いの月次・年次確率を集約し、表紙の設定から選択して localStorage に保存・復元する。日常イベント抽選は第2弾のため、保存値がまだイベント発生には影響しない。

## 採用した仮値

| 項目 | 採用値 |
|---|---|
| 月の時間 | ×1=240ms、×5=48ms、×10=24ms、×20=12ms、停止 |
| 成長（武芸/学問/政務/人付き合い） | +0.12/月。費用は順に0.2/0.1/0.1/0.2貫/月 |
| 家の仕事・商い／休養 | 所持金+0.1貫/月／健康+1/月。どちらも費用なし |
| 能力逓減 | 80以上は通常量の1/2、95以上は1/4、上限100 |
| 年齢配分 | 武芸の伸びを50〜64歳は半分、65歳以上は全量知略へ |
| 年齢変化 | 50〜64歳は誕生日ごと武勇−0.5、65歳以上は−1.0。同量を知略へ |
| 開始金 | 国衆4／家老級8／大名級20貫 |
| 年収段階 | 2／6／18／36／60貫。月次支給の端数は繰越 |
| 健康表示 | 70〜100健やか、40〜69不調、1〜39重篤 |
| 日常イベント頻度 | 少ない: 月1%＋年25%、ふつう: 月3%＋年55%、多い: 月6%＋年80% |

成長量0.12/月は設計案の0.05から上げた。4つの成長方針を3か月ごとに交代する一生シミュレーションで、5人の能力合計変化の平均を設計目安の40〜55点に近づけるための調整。特定能力が初期から高い人物や短命の人物では個別値が目安を下回る。

## 第2弾への申し送り

- 日常イベント抽選は GAME_CONFIG の頻度選択を読み、誕生日・年齢条件・再発冷却と統合する。現在は保存と復元だけ。
- 能力判定は固定難易度方式を使う決定。既存の通常イベントに対する効果表示を土台に、成功・失敗の分岐と判定値の説明を追加する。
- イベントによる家柄・役職変更を状態に反映し、役職段階が変われば年収も連動させる。
- 健康は休養と回復手段に加え、病・怪我・老齢リスク、史実より長生きする共通目標を実装する。
- 月進行・能力・健康・所持金は Engine の状態に集約済み。日常イベントや合戦の仕様を追加しても、年月順イベント処理と既存 `effect` を維持する。
- 能力合計の平均は目標内だが、短命・高能力開始の人物は低い場合がある。運用方針による差も含め、プレイテスト後に0.12/月を再調整する。

## 参考作品へのリスペクトと本作の表現

参考画面からは、能力や蓄えの常時表示、選択前の効果表示、年ごとの生涯記録という仕組みを学んだ。画面レイアウト・色・用語・文章・人物/イベントデータは本作独自として作成し、提示スクリーンショットの画像や文面は取り込んでいない。正式公開時のクレジット文面は、決定メモに従い大澤の承認後に掲載する。
