# タスク003 生涯画面レイアウト修正 報告

完了日: 2026-11-01  
公開先: https://oosawak.github.io/sengoku-life-sim/

## 変更内容

- 表示順を「年月・年齢・能力などの身上 → 心がけ・停止・速度 → イベント → 一生の記録」に並べた。
- 生涯画面中は画面全体のスクロールを止め、画面高に合わせて収める。イベント本文と選択肢が長い場合はイベント欄の中だけをスクロールさせる。
- 一生の記録は画面内の高さを占める専用領域にし、古い記録を残したまま内部スクロールできるようにした。記録は時系列に下へ追加し、新しい記録が来たときは欄内だけ最下部へ追従する。
- イベント表示時にページ全体を `scrollIntoView` しないようにし、イベント欄を先頭に戻す。
- 表紙・出生札・最期と列伝、ゲーム進行、人物・史実イベントデータは変更していない。

## 検証結果

- `git diff --check`: 成功。
- ローカルHTTP: `/`、`/app.js`、`/style.css`、`/data.json` はすべて200。
- 多数の記録はログ領域へappendし、追加ごとに `scrollTop = scrollHeight` とする。ログ領域は生涯画面内の比率で高さを制限し、`overflow-y: auto`、生涯画面は `100dvh` と `overflow: hidden` を使うため、記録が増えてもページ全体は伸びない構造。
- イベント発生時にページを `scrollIntoView` しない。生涯画面は固定高でイベント領域を残り高さに割り当て、長文はイベント欄内でスクロールする構造。
- ブラウザーのスクリーンショットを使った目視確認は未実施。Playwrightは利用できず、GUI操作CLIの `orca` も環境に見つからなかった。スマートフォン実機確認も未実施。
