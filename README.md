# 戦国人生シミュレーション（仮称）

実在の戦国人物に転生して、その一生を生きるブラウザゲームの試作です。
サーバーではプログラムを動かさない、静的サイトとして作っています。

**遊ぶ: https://oosawak.github.io/sengoku-life-sim/**

## 遊び方

1. 「生まれる」を押すと、抽選で転生先の人物が決まります（大名級は低確率、国衆・家臣は高確率）。
2. 年が自動で進み、史実の出来事の年で止まって選択肢が出ます。選んだ結果は評判と寿命に効きます。
3. 最期を迎えると、その一生をまとめた「列伝」が表示されます。コピーして共有できます。
4. 生まれた人物や参加した合戦は、コレクションとして端末内（localStorage）にだけ残ります。

## いまの範囲（v0.1 試作）

- 人物5人: 伊達政宗／伊達成実／天童頼澄／最上義光／直江兼続
- 人物ごとに「宿願」（その人のクリア条件）を1つ持ちます。例: 成実「出奔しても、最後は伊達に戻る」
- 専用イベント15件＋共通イベント1件（慶長三陸地震）
- 同じ合戦を複数の人物の視点で持っています（人取橋／摺上原／天童城／長谷堂）

## データの作り

人物と出来事は Markdown＋frontmatter で定義し、組み立て時に JSON 化しています（Markdown CMSと同じ作り）。

- `content/people/` 人物1人1ファイル
- `content/events/` 出来事1件1ファイル
- `scripts/build.py` が検証つきで `data.json` を生成します: `python3 scripts/build.py`
- 仕様の叩き台は `spec_v0.1-draft.md`

## 材料について

事実関係の確認には「成実三昧」（管理人 TAKEMI Shigino、CC BY-SA 2.1 JP）の変換データと年表を使いました。
ゲームの文章は、事実をもとにすべて新規に書いたオリジナルです。第三者の文章・写真は含みません。
