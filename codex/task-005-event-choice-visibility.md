# Codex指示書 005: イベント選択肢をスクロールなしで表示

宛先: Codex  
発行: 大澤からの会話上の依頼（2026-11-01）  
対象リポジトリ: oosawak/sengoku-life-sim

## 依頼

イベントの回答（選択肢）は、画面をスクロールせずに選べるようにする。

## 作業範囲

- 生涯画面のイベント表示中、ログ欄を隠して選択肢の表示領域を広げる。
- 年月・人物情報などの常時表示をコンパクトにし、イベント本文が長いときは本文欄だけをスクロール可能にする。
- 選択前の選択肢カードを短くし、選択後の結果は従来どおりログに記録する。
- 他画面、ゲーム進行、人物・イベントデータは変更しない。
- 公開ページへの反映には、サイトファイルの変更を含む push が必要。常駐指示に従い、この指示書で push が明示的に許可されるまでは公開しない。

## 成果物

- `app.js` / `style.css` の変更
- `reports/2026-11-01-task005-event-choice-visibility.md`

## 完了条件

- 選択肢が画面内に収まるよう配置され、本文が長くても選択肢へ到達するためのスクロールが不要。
- 報告書に変更内容、確認方法、未確認事項を記載する。
- 公開許可後に commit・push し、公開側で反映を確認する。
