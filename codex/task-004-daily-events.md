# Codex指示書 004: 日々の出来事を含むプレイ体験

宛先: Codex  
発行: 大澤からの会話上の依頼（2026-11-01）  
対象リポジトリ: oosawak/sengoku-life-sim

## 依頼の趣旨

歴史イベントだけでなく、日々の出来事もプレイ中に発生する方がよい。設計の説明に留めず、実際に遊びながら一緒に考えられるものを目指す。

## 作業範囲

- 既存設定の月次・年次イベント頻度を、実際の日常イベント抽選に接続する。
- 日々の出来事の選択・能力判定・成否別結果をゲーム上で処理する。
- 再発冷却、年齢条件、出来事カテゴリの連続抑制を用意する。
- 初期の日々の出来事データを `content/daily-events/*.md` に追加し、`data.json` に生成する。
- 歴史イベントを優先し、日々の出来事と同じ月に重ねない。
- サイトファイルの変更、mainへのcommit/push、およびGitHub Pagesへの公開を許可する。
- 既存の人物・歴史イベントの史実データは変更しない。
