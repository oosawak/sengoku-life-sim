# コーデックス常駐指示（このリポジトリ専用）

この文書は、このリポジトリ（oosawak/sengoku-life-sim）で作業するコーデックスへの常駐指示。
このプロジェクトの指示・成果物・報告は、すべてこのリポジトリの中で完結させる。
ネタ帳（neta-cho）は経由しない。

## 見る場所

- 指示書: このフォルダ（`codex/`）にある `task-*.md`。ファイル末尾に「状態: 完了」と書かれていないものが未処理の指示書。
- 作業を始める前に、必ず `git pull` して最新にしてから読む。
- この文書自体が更新されていたら、新しい内容に従う。

## 作業の進め方

- 指示書の内容と範囲を厳密に守る。範囲の外のことはしない。
- 成果物は指示書に書かれた場所に置く。
- 作業の途中で、人に確認を求めて止まらない。判断に迷う点は「未決事項」として報告書に書き、進められる部分を進める。
- 既存の人物・イベントデータの事実関係（生没年・出来事・宿願）は、指示書に明示がない限り変えない。

## 終わったら

- 報告書を `reports/YYYY-MM-DD-<slug>.md` に置く（形式は各指示書の指定に従う）。
- 実施した指示書ファイルの末尾に「状態: 完了（報告: reports/<ファイル名>）」を追記する。
- 変更は commit して push する。ミューズは報告書をこのリポジトリから読んでチェックする。

## 外向きの行動について

- このリポジトリは public で、main への push はそのまま GitHub Pages の公開に反映される。サイトのファイル（`index.html`／`app.js`／`style.css`／`data.json`／`content/`）の変更を含む push は、指示書に明示されている場合だけ行う。
- SNS 等への告知・宣伝はしない（大澤の判断事項）。
