# Codex指示書 006: イベントの種別（史実／伝承／創作）をゲーム内に印で表示する

宛先: Codex
発行: 2026-11-01（大澤の方針決定を受けてミューズが発行。根拠は docs/decisions-v0.2.md の方針メモ009）
対象リポジトリ: oosawak/sengoku-life-sim

## 背景

大澤の方針: 史実と創作は混ぜてよい。ただし、どれが史実でどれが創作かは、データに明記し、ゲームの中でも遊ぶ人が見分けられるようにする。

データ側は対応済み: 史実イベントと日常イベントの全件に `basis` フィールドが入っている（`fact` / `legend` / `fiction`）。`scripts/build.py` は basis をそのまま data.json へ通すことを確認済み。今回は表示だけが残っている。

内訳（参考）: 史実イベント26件 = fact 24件・legend 2件（頼澄の多賀城石碑、利府の晩年）、日常イベント9件 = fiction 9件。

## 作業範囲

- 生涯画面のイベント表示に、basis に応じた小さな印を出す。
  - `fact` → 「史実」
  - `legend` → 「伝承」
  - `fiction` → 「創作」
- 史実イベント・日常イベントのどちらにも同じ形で出すこと（既存の「日々の出来事／史実イベント」の区別表示と並んでも煩くならない、控えめな見た目にする。色づかいは既存の紙色・朱色の世界観に合わせる）。
- `basis` が無いイベントでは印を出さない（将来のデータ追加に備えた既定動作）。
- イベントの文章・データ・進行の仕組みには手を入れない。
- 列伝やコレクションへの印の表示は今回の範囲外（必要なら別途指示する）。
- サイトファイルの変更、mainへのcommit/push、GitHub Pagesへの公開を許可する。

## 表現上の注意

- 印は「これが絶対の事実だ」という断定の表示にしない。あくまで種別の目安である（方針メモ009）。
- 参考作品の画面意匠・文面を取り込まないこと（従来どおり）。

## 完了条件

- 公開側（ https://oosawak.github.io/sengoku-life-sim/ ）で、fact / legend / fiction の3種の印がそれぞれ実際のイベント表示で確認できること。
