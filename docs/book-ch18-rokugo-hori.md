# 本 第18章 若林城を貫く水

> 状態: 雛形（2026-11-02）。構成案 v0.1 第6部・第18章。第5弾素材が核。
> 進め方: この雛形をもとに本人と話しながら本文を書く。

## この章の狙い
- 六郷堀は若林城の堀どころか、城内を貫通していた。発掘報告書が明かした若林城の水利を描く。

## 節立てと書くこと
### 西門から東門へ
- 仙台市文化財調査報告書第474集: 六郷堀は西門から入り東門から出たと考えられ、表御殿の大池へも分水していた。「若林城の水利の根幹」。開削は若林城と城下の造営と大きく関わる。
- 若林城は土塁と幅25mの水濠の「土の城」で、石は少ない。
### 二つの堀の取水
- 七郷堀・六郷堀は広瀬川の愛宕堰で取水し分水する仕組み。
