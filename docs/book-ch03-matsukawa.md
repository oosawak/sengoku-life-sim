# 本 第3章 松川の戦い ― 取り戻せなかった旧領

> 状態: 雛形（2026-11-02）。構成案 v0.1 第1部・第3章。
> 進め方: この雛形をもとに本人と話しながら本文を書く。

## この章の狙い
- 慶長出羽合戦の福島戦線。伊達が「置いていかれた旧領」を取り戻そうとして失敗した戦いとして描く。
- 軍記色の強い逸話であることを添え、研究者の疑義も隠さない。

## 節立てと書くこと
### お墨付きの旧領
- 家康のお墨付きは旧領6郡49万石の自力回復を許すものだった。福島・信夫郡はその中核。
### 信夫山の陣と背後の梁川
- 伊達勢は信夫山の黒沼神社付近に陣し、松川を挟んで本庄繁長と対峙（福島市公式・『信達一統志』）。
- 梁川城の須田長義が背後から攻め、小荷駄方を襲い本陣の帷幕を奪った。
### 10月6日の進言
- 横田大学の内通を受け、片倉景綱が「梁川城を6日のうちに攻略すべし」と進言。政宗は先送りの返書。
- 梁川は広瀬川の断崖の上の山城。囲んで釘付けにし平地の福島を先に落とす判断自体は合理的だったが、釘付けが漏れた。
- 【本人の話】「梁川城をちゃんと取ればよかった」という本人の現地感覚。
### 喜多の二人の弟たち
- 前線を担った茂庭綱元と片倉景綱は、片倉喜多を挟んだ義理の兄弟。
- 福島の町曲輪まで攻め込んだ景綱が撤退を進言し、石川昭光も再攻撃中止を言上した。指揮官の配置は能力順ではなく身分順（成実は昭光の軍に属した）。
### 二度落とせなかった男
- 本庄繁長は越後の古強者。二度攻めて二度とも落とせず、減封後も福島は本庄が治めた。
