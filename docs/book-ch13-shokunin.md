# 本 第13章 街道と裏通りの職人たち

> 状態: 雛形（2026-11-02）。構成案 v0.1 第5部・第13章。第2話の分割後半。
> 進め方: 本の章として新たに書く。yomimono-002 の街道・田町・職人町の材料は素材として参照するが、章立ては本の都合で決める。

## この章の狙い
- 奥州街道の折れ目と若林の職人町（鍛冶・材木・染師・畳・石切）を歩く章。第6部（水と堀）への橋渡し。

## 節立てと書くこと
### 南の入口・河原町
- 丁切根（木戸）は東西南北4か所、開閉は6時〜18時。南の木戸は河原町の南入口（現・河原町一丁目付近）。木戸番は代々針生家。針生家の屋敷と針惣旅館は木戸の内側の南材木町にある。
- 寛永17年（1640年）に青物市場。
### 田町
- 町方二十四カ町の一つ・序列13位。開府当初は宮沢渡し→舟丁→大町への南玄関口。城普請協力の褒美に紙専売。明治6年に田新町と合併、住居表示で五橋に吸収され消滅。今は田町通りと辻標No.29に名が残る。
### 職人町を歩く
- 南鍛冶町（奥州街道の折れ目にある逆L字型、南北分離の経緯、枡形）、穀町（米問屋、四穀町の一つ）、南材木町（若林城造営時の材木町、材木と煙草の専売）、南染師町（瑞鳳殿造営に伴い越路から移転、間口6間半）、畳屋丁、荒町の移転（寛永4〜5年頃、若林城築城に伴い現在地へ。夏の副業は渋団扇）。
- 石切町は第20章（二つの石切町）で本格的に扱い、ここでは触れるだけにする。
