# 本 第23章 海の玄関 ― 塩釜と松島

> 状態: 雛形（2026-11-02）。構成案 v0.1 第7部・第23章。第4弾素材（城と社寺と水の線）が核。
> 進め方: この雛形をもとに本人と話しながら本文を書く。瑞巌寺の「最後の砦」説は寺伝レベルと明記する。

## この章の狙い
- 要所の高台に置かれた社寺の配置を、塩釜神社と瑞巌寺で描く。
- 1611年と2011年、二度の津波で水の届かなかった場所と街道の線が重なる話。

## 節立てと書くこと
### 丘の上の塩釜神社
- 港を見下ろす急な丘の上。大崎八幡宮・亀岡八幡宮・経ヶ峯と並ぶ「要所の高台の社寺」の配置。
### 瑞巌寺という砦
- 山を背に松島湾に面する配置。「最後の砦」説（寺伝・地元の語り）: 畳の厚さ9センチ、武者隠し、陸路は長老坂一筋、海路で補給・脱出の青写真。
### 二度の津波
- 慶長16年（1611年）も2011年も、政宗の選んだ場所は水の届かない場所だった。2011年は参道の4分の3まで浸水したが本堂は無事で、住民の避難先になった。松島は島々が防波堤になり被害が軽かった。
- 【本人の話】松島に友人が多く住む本人の実感。
### 長町の蛸薬師
- 洪水で蛸に吸い付かれた薬師様が流れ着いた言い伝え（舞台八幡神社）。慶長の津波の広瀬川遡上か後の洪水かは未特定、と明記。
