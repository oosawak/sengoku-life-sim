# 本 第19章 二つの堀と小舟

> 状態: 雛形（2026-11-02）。構成案 v0.1 第6部・第19章。第5弾素材が核。
> 進め方: この雛形をもとに本人と話しながら本文を書く。本人の仮説は仮説として書く。

## この章の狙い
- 「堀を小舟で材木や人を運んだのではないか」という本人の仮説を検証する章。記録の有無を正直に書く過程そのものを見せる。

## 節立てと書くこと
### 七郷堀の仕事
- 灌漑、南染師町の染色用水（別名「藍染川」、染師の家は「川戸」を備えた）、防火・生活用水。
### 舟運の記録を探す
- 七郷堀の舟運を示す直接の記録は未発見。人の移動に舟を使った記録も未発見で、表ルートは河原町から東へ直進する新道だった。
- 幹線の舟運は広瀬川の舟丁（閖上から遡上、御米蔵・御材木蔵）。七郷堀の国道4号の橋は今も「蔵前橋」という名が残る。
### ただし、発想は実在した
- 木流堀は農産物の運搬に使われ、1711年に建築用材を運べるよう改修された実例がある。堀を資材運搬に使う発想は仙台に実在した。
- 材木の本線: 広瀬川→舟丁→若林の御材木蔵。石は大坂城・江戸城の例では水運が常道だが、仙台城の石は三滝・郷六・国見峠付近・大石原の石切場から調達された。
