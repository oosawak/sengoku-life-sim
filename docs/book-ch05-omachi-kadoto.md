# 本 第5章 大町は門東町だった

> 状態: 雛形（2026-11-02）。構成案 v0.1 第2部・第5章。
> 進め方: この雛形をもとに本人と話しながら本文を書く。

## この章の狙い
- 伊達時代の米沢の大町は今の門東町で、上杉入部後の三の丸堀で外へ移された。今の大町は二代目。
- 仙台の大町の起源は米沢にある、という移転の連鎖を描く。

## 節立てと書くこと
### 城の東の町人町
- 伊達期の大町は城の東、三の丸堀に接した町。六町（大町・粡町など）の起こり。
### 三の丸堀と町の移転
- 慶長13年（1608年）の三の丸堀掘削で大町は外へ移され、跡地は門東町となった。
### 大町という名前の旅
- 米沢→岩出山→仙台。大町通は仙台城下設計時の東西の基線になった。
- 『伊達輝宗日記』天正2年4月3日条「大町にて騎馬」の話は第6章へつなぐ。
