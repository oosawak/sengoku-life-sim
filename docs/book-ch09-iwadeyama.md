# 本 第9章 迷い込む岩出山

> 状態: 雛形（2026-11-02）。構成案 v0.1 第4部・第9章。本人の巻タイトル案「政宗と迷い込む岩出山」を章題に転用。
> 進め方: この雛形をもとに本人と話しながら本文を書く。

## この章の狙い
- 1591年から仙台開府までの12年、政宗の雌伏の本拠・岩出山を描く短い部。
- 町割りの痕跡と「仙台の予行演習」としての岩出山。

## 節立てと書くこと
### 岩手沢から岩出山へ
- 1591年、奥州仕置で下向した家康が約40日滞在して城を修復し政宗に引き渡したとき「岩出山」と改められた。命名は家康とも（第1話で使用済みの材料）。
### 12年の町割り
- 政宗が町割りを行ったと伝わる。岩出山の町名: 南町・北町・川原町・浦小路・通丁・大学町・東川原町・下川原町など。○○人町は見つからず（第4弾素材）。
- 会津・米沢から寺を呼び寄せた話（要調査）。
### 仙台への助走
- 1600年の北目城の拠点化と仙台開府へつなぐ。
