## これは何か

山形県置賜地方の中世城館跡の名鑑。伊達家家臣らの城館群「伊達四十八館」に準えて、置賜に100以上ある城館跡から主要48か所を市町村別に掲載している。伊達氏と置賜の関係の解説と「中世置賜の変遷」表、城館の遺構用語（詰城・根小屋・縄張・郭・虎口・土塁・堀など）の解説つき。

置賜はもともと長井氏（大江広元の次男・時広を祖とする）の領地で、伊達氏8代宗遠・9代政宗が攻めて支配下に置いた土地。15代晴宗が本拠を米沢へ移して奥州探題となり、17代政宗は米沢で生まれ、25歳まで置賜で過ごした。

## 使い方（このプロジェクトでの位置づけ）

- **事実確認用**。人物データの裏取り（居城・本拠地・年代）と、合戦・城館を実在の場所と結びつけるときの照合先として使う。
- **文章の転用はしない**。解説文を写さず、事実関係の確認だけに使う（他の参考資料と同じ線引き）。
- 人物・出来事に「場所ID」を持たせる設計（`docs/people-candidates-v0.1.md` の連動メモ）で、城館は場所IDの候補になる。

## 本作の人物・イベントと関わりそうな点（要検証の対応候補を含む）

- **米沢城**: 政宗の生誕地で伊達の本拠。関ヶ原後は上杉の本拠となり、兼続の米沢移封（既存イベント kanetsugu-1601-yonezawa）の舞台。場所IDの筆頭候補。
- **変遷表の年次**は、既存イベントの年代照合に使える:
  - 1548年 晴宗が本拠を米沢へ移す
  - 1567年 政宗、米沢で誕生
  - 1589年 摺上原の戦いで伊達氏最大版図
  - 1591年 政宗が岩出山へ移り、置賜は蒲生領に
  - 1598年 置賜は上杉領となり、米沢に直江兼続が入る
  - 1601年 上杉氏が米沢に本拠を移す
- **屋代館（高畠町）**: 人物候補の屋代景頼（伊達家臣）との対応が考えられる。要検証。
- **片倉館（長井市）・片倉山館（米沢市）**: 片倉氏（景綱ら）との対応が考えられる。要検証。
- **資福寺館（高畠町）**: 名前は政宗の師・虎哉宗乙ゆかりの資福寺を思わせるが、同一の寺・場所かどうかは未確認。混同しないこと。
