# 本 第6章 二つの八幡

> 状態: 雛形（2026-11-02）。構成案 v0.1 第2部・第6章。
> 進め方: この雛形をもとに本人と話しながら本文を書く。

## この章の狙い
- 『伊達輝宗日記』天正2年（1574年）4月3日条の八幡参詣先はどこか、という未決着の謎を、そのまま謎として楽しむ章。
- 片倉景重の表記を「米沢八幡の神職」とする理由もここで説明する。

## 節立てと書くこと
### 日記の一文
- 八幡参詣の帰路「大町にて騎馬」（コトバンクの現代語要約であり、原文そのものではない点に注意）。
### 候補は二つ
- 成島八幡: 城から約5km北西。帰路で大町を通らない。
- 安久津八幡神社（高畠）: 城から東へ約10km。帰路で大町を通る。伊達氏時代に境内に十二坊を抱えた古社で「東の八幡様」。
- 【本人の話】現地感覚。成島は「普通だった」、安久津は「本当にやばかった」。
### 片倉景重という人
- 「米沢八幡の神職・片倉景重」と書く約束（社名を特定しない）。「米沢八幡宮」という社は現存せず諸説ある。
- 『武家家伝＿茂庭氏』の「成島八幡神社神官」表記は後世の家伝の書き方として扱う。白石市の講演録には景綱は神官の子ではなかったという系譜検証もある。
### 仙台の伊達八幡との区別
- 晴宗の守本尊を祀り慶長5年に米沢から移された伊達八幡神社（仙台）と、朝宗が1189年に勧請した氏神・亀岡八幡宮は別系統。混同しない。
