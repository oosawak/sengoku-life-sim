# 本 序章 仙台という範囲

> 状態: 雛形（2026-11-02）。本の構成案 v0.1 の序章。

## この章の狙い
- なぜ「仙台」の本が福島から水沢まで及ぶのかを、最初に読者へ渡す。
- この本の約束事（史実・伝承・創作の区別、本人の記憶は本人の声として書く）を明示する。

## 節立てと書くこと
### 仙台は藩の名前だった
- 旧仙台藩の範囲（白石〜水沢）と、旧伊達領（伊達郡・置賜・会津）を合わせた地理がこの本の舞台。
- 伊達家の移転の略史を1ページで: 伊達郡→米沢→会津→岩出山→仙台。
### この本の約束事
- 分からないことは「分からない」と書く。通説と同時代史料は分ける。
- 【本人の話】なぜこの範囲に愛着があるか（生活圏＝仙台・山形・福島の移動と重なる話）。
