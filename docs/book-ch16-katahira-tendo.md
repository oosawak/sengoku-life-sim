# 本 第16章 片平の屋敷街 ― 天童様の家

> 状態: 雛形（2026-11-02）。構成案 v0.1 第5部・第16章。新規（2026-11-02の発見）。
> 進め方: この雛形をもとに本人と話しながら本文を書く。

## この章の狙い
- 元禄の五釐絵図で見つけた「天童修理」の区画から、重臣たちの屋敷街・片平を歩く章。

## 節立てと書くこと
### 地図の上で見つけた家
- 2026-11-02、再生古地図（元禄五釐絵図）で本人が発見。七軒丁・桜小路の近く、中嶋伊勢の区画の南に「天童修理」。
- 現在は東北大学片平キャンパスの体育館・電気通信研究所あたり（米ヶ袋）。
### 並びの人々
- すぐ隣が中嶋伊勢、東へ和田織部、片平弥五郎。七軒丁の向かいは大町備前、本田京之丞。西の大きな区画は天満宮別当と石川中務（伊達一門の石川氏とみられる）。南東に窪田伊兵衛。
### 在所と屋敷、二つの場所
- 天童家は多賀城・八幡に在所を持ち（1681年の在所絵図あり）、別に仙台城下にも屋敷を持っていた。元禄時点の当主は重頼から数えて数代後。
- 【本人の話】地図アプリで探す楽しさ、スライダーボタンの下に隠れた「天」の字の話など、発見の経緯。
