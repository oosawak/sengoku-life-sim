# 本 第20章 二つの石切町

## この章の狙い
- 仙台には石工の町が二つある。八幡の石切町と南石切町。出身も招かれた理由も違う二つの町を、石工という仕事で結ぶ。

## 節立てと書くこと
### 八幡の石切町
- 現・青葉区八幡2丁目の一部。仙台城の石垣のために堺から招かれた石工の町。雀踊りの発祥と伝わる。黒田家・小梨石材店が今も残る。→第14章の八幡町と接続。
### 南石切町
- 南材木町の東裏。寛文4年（1664年）の絵図に「石垣衆」。近江から招かれた石工で、灯籠・鳥居・墓石を手がけた。→第13章の職人町と接続。
### 小学校が町を切り取った？
- 南材木町小学校は1873年開校、1885年に現在地へ移転、1912年の校地拡張で総坪3,216.31坪。「南石切町を切り取った」と直接示す資料は未確認。仮説の範囲で書く。
- 【本人の話】小学校の学区に若林の職人町・足軽町がそのまま入っていること。
