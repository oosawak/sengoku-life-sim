# 本 第11章 若林の足軽町

> 状態: 下書き（2026-11-03）。構成案 v0.1 第5部・第11章。本の章として新たに書いた（ブログ第1話・第3話は素材として参照のみ）。
> 材料: 仙台市「町名に見る城下町」ほか市の資料、yomimono-001／003。数の編成についての見立ては本人のものとして本文に明記した。

## 足軽の町が固まっている

第10章で書いた五十人町の周りには、似た成り立ちの足軽町が固まって並んでいる。三百人町、六十人町、柴田町、成田町、弓ノ町。仙台城下の南東、若林の一角は、足軽の町の一大集積だった。

並べてみると、この町々は大きく二つの型に分かれる。故郷ごとに人を集めて編んだ町と、専門の腕で人を集めて編んだ町である。どちらの型も、町名がそのまま設計図になっている。

## 置いていかれた人たち

三百人町の話は、この本の始まりの方の話とつながっている。

第1章で書いたように、伊達家は1591年の移封で伊達郡を失い、梁川の人たちは置いていかれた。第3章の松川の戦いでは、その梁川の城が伊達の背後を突く側に回った。それほどまでに、旧領の人たちとの関係は切れていたように見える。

ところが1600年、関ヶ原の年の白石城攻めのとき、伊達郡のかつての家臣たちが伊達方として参加し、その働きで再び伊達家に仕えることになった。その人たちのために割り出された町が、三百人町である。

町の鎮守は信夫神社で、慶長15年（1610）に信夫郡の神社を勧請したものだという。故郷へ戻るのではなく、故郷の神社を連れて、仙台の城下に移り住んだ。置いていかれた人たちが、今度は城下の守りの側に回ったことになる。

第10章で触れた実測では、三百人町の広さは五十人町とほぼ同じだった。300人の町と50人の町が同じ広さというのは、頭数の単純な話ではないのだろう。編成の実態はまだ解明できていない。

## 出身地の町

柴田町は、柴田郡の出身の足軽169人の町である（寛永10年ごろ）。鎮守は白鳥神社で、故郷の柴田郡の大高山神社を勧請したものが、後にこの名で呼ばれた。読みは「しらとり」。

ややこしいことに、六十人町の鎮守は城取神社で、こちらは「しろとり」と読む。由来は、寛永3年（1626）の城下の町割りのときに使った縄を埋めて祀った、というものである。町を作った道具そのものが神様になった。読みのよく似た二つの神社が、足軽町同士の隣り合う町に並んでいる。

成田町は、桃生郡成田村（今の石巻市河北あたり）から来た足軽60人の町である。大番組に属し、組の旗を護衛する役目だったという。戦場で旗を預かるのは、信頼の置ける者にしか任せない役である。町の鎮守は、故郷から勧請した箱石神社である。

出身地の町々に共通するのは、故郷の神社を持ってきたことだ。人は移り住んでも、祀る神は故郷のままだった。町は、移住した人たちの故郷の分身だったのである。

数の話を少しだけ。20、50、60、300と、町名の数字はばらばらに見える。30を基数に考えると60と300は収まりがいいが、20と50は収まらない――これは私の見立てで、仙台藩の標準編成を明記した資料は見つかっていない。数字の謎は、まだ解けていない。

## 専門の町

もう一つの型は、腕で編んだ町である。

弓ノ町は、弓足軽の組の町（寛永10年ごろ）。石垣町は、寛永5年ごろに取り立てられた御作事方、つまり建築や土木を担う職方の足軽の屋敷町である。東八番丁の一帯も当初は足軽屋敷で、大河原村の出身の鉄砲足軽が住んで「大河原町」とも呼ばれた。こちらは出身地と専門の両方が重なった町である。

石名坂、連坊小路といった名も、この足軽町の一角に残る。鉄砲、弓、作事。道具と腕で編成された町が、城下の南東に並んでいた。

## 貧しさを歌った歌

連坊小路のあたりには、足軽町の貧しさをからかった戯れ歌が残っている。

「連坊や かたふさかけて 柴田町 成田（なんだ）三百 五十 六十」

町名を数え歌のように並べた、からかいの歌である。

実際、足軽の禄は少なく、庭で野菜を作って河原町の市場で売ったり、筆作りの内職をしたりして暮らしたという。戦の時代には旗を任され、故郷の神社を祀ることを許された人たちが、太平の世では薄給に甘んじた。その落差ごと、歌にされて残った。

## もう一方の若林へ

若林の足軽町群は、数で言えば、城下の南と東の守りの厚さそのものである。なぜ守りが南と東に厚いのかは、第14章と第15章で改めて考える。

そして若林には、もう一方の人たちがいた。代々、主についてきた町人たちである。次章は、その御譜代町の話になる。
