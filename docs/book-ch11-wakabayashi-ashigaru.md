# 本 第11章 若林の足軽町

> 状態: 雛形（2026-11-02）。構成案 v0.1 第5部・第11章。第1話後半＋第3話の若林分の再編。
> 進め方: 元原稿をもとに重複を落として再構成する。

## この章の狙い
- 若林城下の足軽町群（三百人町・六十人町・柴田町・成田町ほか）を、出身地と専門職の二つの型で描く。

## 節立てと書くこと
### 置いていかれた人たち（三百人町）
- 伊達郡の旧臣が1600年白石城攻めに参加して再び仕えた話。信夫神社（慶長15年に信夫郡から勧請）。→第3章・第1章からの回収。
### 出身地の町
- 柴田町（柴田郡169人、白鳥神社＝大高山神社の勧請）、成田町（桃生郡成田村60人、旗の護衛、箱石神社）。六十人町の城取神社（寛永3年の町割りの縄の由来）。
### 専門の町
- 弓ノ町、石名坂、石垣町（御作事方の足軽屋敷）、連坊小路。東七・八・九番丁の当初は足軽屋敷だった話。
### 貧しさを歌った歌
- 連坊小路の戯れ歌と、足軽の内職（筆作り、野菜売り）。
