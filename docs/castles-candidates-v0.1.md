# 城館候補リスト v0.1（ゲーム側の候補池・材料リスト）

作成: 2026-11-01

## 位置づけ（最初に読むこと）

- **これは城館データの正本ではない。** 城館データの正本の形式は、別チャットで作っている「戦国ガイドサイト」側で設計する（`docs/decisions-v0.2.md` 方針メモ006）。本書は、ゲーム側が先に集めた**候補池・材料リスト**であり、ID・座標・分類はすべて候補段階のもの。正本の形式とID体系が決まったら、そちらに合わせて移す。
- 方針メモ006の約束どおり、本作の本データでは城館をIDで参照し、緯度経度は正本側の値を参照する。本書の座標も正本化しない（あくまで候補段階の照合用）。
- 種別 `basis` は方針メモ009の区分を使う: `fact`（実在が確か）／`legend`（実在・位置・由緒に伝承や諸説が大きい）／`fiction`（創作。今回は収録なし）。
- 緯度経度は Wikidata（P625）で確認できたものだけを書き、QIDを併記した。確認できないものは「未取得」と正直に書く。推測の座標は入れていない。
- 関係する人物は `docs/people-candidates-v0.2.md` の名前で対応付けた。対応が推定のものは「（要検証）」を付けた。
- 文章はすべて自前で書いた。参考サイトからは名称・市町村・所在地などの事実だけを使い、解説文は転用していない。

## 材料と確認の方法

- 置賜四十八館の名称と市町村別構成: 「伊達な置賜四十八館｜置賜城館名鑑」（https://sengoku.oki-tama.jp/dte48/ ）の掲載事実。巻頭8館は同サイトの個別ページで市町村を確認した（2026-11-01閲覧）。まとめは `docs/reference-okitama-48-castles.md`。
- 主要城の座標の土台: `docs/collection-prototype-v0.1.md` のWikidata収集結果（15件中13件）。
- 今回追加でWikidata確認した城: 小国山城、相馬中村城、棚倉城、亘理城、三春城、須賀川城、猪苗代城、向羽黒山城、小峰城（歴史館）。
- 同名の別城の誤認に注意した実例: Wikidata検索で「高畑城」は陸奥国（青森）の城、「荒砥城」は長野の城、「原田城」は摂津の城が第1候補に出る。置賜のものとは別なので採用していない。

## 次工程への申し送り
