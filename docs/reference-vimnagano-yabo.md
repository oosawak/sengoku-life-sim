## これは何か

Vim / Neovim の中だけで動く、信長の野望・武将風雲録風の戦国シミュレーションゲーム（レガシー Vim script 製、外部依存なし）。

## 参考になる点（本作との対応）

1. **月次処理の順序**
   自家の行動 → AI各家の行動 → 月末処理（商業収入、兵糧消費、9月の収穫、台風・一揆イベント）という完成した型がある。
   本作の第1弾（月進行ループ）の処理順序を組むときの物差しになる。

2. **数値の比率感**
   開発・商業は金200、施しは金100＋米100、外交の贈物は金500、官位の献金は金1000 など、収入に対する行動コストの置き方。
   通貨単位は本作（貫）と違うが、「月収・年収に対して1回の行動がいくらか」の感覚は、貫の仮値（指示書002）の調整に使える。

3. **状態がイベントを呼ぶ作り**
   民忠25未満で一揆の危険、というように「数値の状態がリスクを生む」設計。本作の健康→病死リスク（決定003）と同じ発想の実例。

4. **武将は月1回しか働けない（行動力の制約）**
   武将数がそのまま月の行動力になる。本作の「方針は月に1つ」という制約と同型で、リソースとしての時間の扱いの参考になる。

5. **シミュレーションによる検証**
   `:SengokuTest` でマップ整合性チェックに加え、AI31家による36か月シミュレーションと描画検証が走る。
   本作の指示書002でも「70年の一生シミュレーションで能力推移・残高を検証する」方針を取っており、その方向の裏付けになる。

6. **合戦の自動解決の割り切り**
   籠城戦は戦術マップで遊ぶ作りだが（本作は「采配だけ選ぶ」方針で対照的）、AI同士の合戦は自動解決（守備側2割ボーナス、兵が4分の1になったら撤退）。
   本作の合戦（後工程、方針メモ004）の自動処理の考え方の参考になる。

7. **能力値が式に効く例**
   外交の成功率は「25 + 魅力/3 + 文化/5 + 茶器×4（最大90%）」。本作の判定は固定難易度方式（決定005）にしたが、合戦の危険率など確率で扱う部分の式の置き方の参考になる。
