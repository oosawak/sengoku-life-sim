# 人物候補マスター v0.2（300人規模への拡張版）

作成: 2026-11-01（v0.1 の種リスト100人を土台に、家ごとの広げを行った拡張版）
位置づけ: v0.1 の方針（地域版・役割分け・関係の網）をそのまま引き継ぎ、v0.1「次の抽出の進め方」1. の指定どおり、家ごとに当主の前後2代と主要な配偶者・子供を足して候補池を300人規模へ広げたもの。本データ（能力値・宿願・紹介文）は未作成。

## v0.2 での変更点

- v0.1 の100人は、名前・生没年・地域・役割・優先度・絡みの芯を **v0.1 の記載どおり** 引き継いだ（引き継ぎ分の食い違いは直さず、関係メモ側に注記した）。
- 新規追加分は名前の後に `※新規` を付けた。
- `関係メモ` の列を新設した（親子・夫婦・主従など）。関係の別リスト化は次の工程。
- 新規分の生没年は、Wikidata（wbsearchentities / wbgetentities、P569/P570）と収集試作（collection-prototype-v0.1）の照合で確認できたものだけを年として書いた。確認できないものは `未確認` とし、片方だけ分かったものは `未確認-1620` のように書いた。推測で年は作っていない。
- 年は日本の年で表す。Wikidata の年はグレゴリオ暦換算で1年ずれる場合があるため、旧暦1月没などは日本の年へ寄せた（例: 直江兼続の没年は1619）。
- 同名の別人の取り違えに注意した（相馬義胤の江戸期同名藩主など）。疑わしいものは関係メモに `要確認` と注記した。

## 方針（v0.1 から引き継ぎ）

- 参考作の規模感は、収録4,948人（うち生年が分かっている転生対象3,236人）。ただし本作は全国版ではなく、**宮城・山形・福島で楽しめる地域版**にする。全国の有名人物を薄く集めるのではなく、この3県の土地・城・合戦・寺・家に濃く絡む人を厚く集める。
- 候補は「転生できなくてもよい」。役割を分ける。
  - `転生`: 生年が（試作値でも）置けて、一生の形が作れる人
  - `登場`: 転生先にはしないが、親・子・主君・敵・師として他人の一生に登場する人
  - `両方`: どちらにも使える人
- 抽出の軸は、家と関係である。当主だけでなく、両親・配偶者・子供・兄弟、家臣、敵対者、同盟（最上八楯など）、師匠・僧まで入れる。人が絡む網の目が面白さになる。
- 生没年はこの段階では「分かった範囲」でよい。不明・諸説ありは隠さず `未確認` や `？` を付ける。ゲーム用の試作値を置く場合は、本データ化のときに注記する（天童頼澄の前例どおり）。
- このマスターは将来、そのまま人物解説コンテンツ（人物事典・家系の絡み・ゆかりの地案内）の土台にもなる。ゲーム用データと解説用コンテンツは、同じ人物IDでつなぐ。

## 記号

- 優先度 `S`: 最初に本データ化したい濃い候補 / `A`: 次の波 / `B`: 池の厚み・登場用
- 生没年の `？` は諸説あり・要追加検証、`未確認` はこの段階で年を置かないもの。
- `※新規` は v0.2 での追加分。

## グルメサイトとの連動（将来像）（v0.1 から引き継ぎ）

このゲームの舞台は、本人のグルメ3サイト（山形・宮城・福島）と市町村グルメ地図の守備範囲と重なる。人物・出来事・城・合戦場・寺に「場所ID」を持たせれば、連動は自然に起きる。

- 人物・出来事の解説コンテンツ → 「ゆかりの地のいま」として、その市町村のグルメ地図・店記事へつなぐ
- グルメサイトの市町村ページ → 「この地の戦国人物・出来事」として、ゲーム側の人物・合戦へつなぐ
- ゲームで一生を終えた場所・合戦場 → 現在の地図と近くの店を表示する（ただし店と歴史の関係を偽らず、「近くの店」と明示する）
- 人物マスターは、ゲーム用データと解説コンテンツで共有する。解説側はゲームと別コンテンツとして育てられる

連動は後工程とするが、場所IDと市町村の対応だけは、人物データを作る最初の段階から入れておくと後で困らない。

## 追記（2026-11-01、方針メモ006）: 場所IDは城館データと揃える（v0.1 から引き継ぎ）

城館データは、別プロジェクト「戦国ガイドサイト」で形式を設計して作ることになった（大澤の決定）。データの正本は1つで、本作は参照する側になる。

- 人物・出来事・合戦から城館を指すときは、城館データのIDで参照する。
- 緯度経度は本作側に持たず、城館データ側を参照する。
- 上の連動メモで言う「場所ID」は、この城館データのIDと揃える前提で入れる。
